# mydubai-broker-backend
My Dubai Broker Backend — A secure, scalable, and maintainable backend API developed with TypeScript, powering authentication, user profiles, property listings, and broker operations for the My Dubai Broker platform.

This repo is one half of a two-repo workspace. For architecture, setup, and current implementation status, see `../README.md` and `../PENDING.md` at the workspace root (one level up) — start there, not here.
